# Neon Drift Racer

A small, browser-based lane-dodging game. Move between three lanes, avoid traffic, and build a high score.

## Run it

Open `index.html` in a modern browser. The game uses plain HTML, CSS, and JavaScript and needs no build step or external assets.

## Controls

- Start: enter a driver name and select **Start driving**.
- Steer: use the left and right arrow keys or `A` and `D`.
- Touch screens: swipe left or right on the road.
- Pause/resume: press `Space` or use the pause button.
- Restart: select **Race again** or press `Enter` after a crash.

Sound and reduced motion can be toggled on the start screen. Your best distance is saved in browser storage when available.
